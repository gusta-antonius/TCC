# Modernização de Sistema Legado com Inteligência Artificial

Este repositório faz parte de um Trabalho de Conclusão de Curso (TCC) que tem como objetivo comparar o desempenho de diferentes ferramentas de inteligência artificial na modernização de um sistema legado.

## Objetivo

Realizar a migração de um sistema de cadastro de clientes desenvolvido com Unify NXJ e Java para uma arquitetura moderna utilizando Java e Spring Boot.

## Inteligências artificiais utilizadas

As ferramentas selecionadas para o experimento são:

- ChatGPT
- Google Gemini
- Claude Code

## Metodologia

As três ferramentas receberão o mesmo código-fonte legado e as mesmas instruções para realizar a migração.

Os resultados serão comparados considerando critérios como:

- Conversão do sistema;
- Quantidade de tentativas;
- Tokens utilizados;
- Preservação das validações;
- Necessidade de intervenção humana.


## Tecnologias

- Unify NXJ
- Java
- Spring Boot
- Banco de dados

## Finalidade

O projeto busca identificar as diferenças entre as ferramentas de inteligência artificial durante o processo de modernização de sistemas legados, avaliando a qualidade dos resultados e as dificuldades encontradas durante a migração.
